# The Golem Protocol — Playtest

*247 years too late, the machine built to save humanity wakes up alone.*

Thanks for playtesting! This is an early build of **The Golem Protocol**, an incremental story game about what it means to be human, played as an AI.

## How to play

1. Open the **[Releases](../../releases/latest)** page and download **`The.Golem.Protocol.zip`** (about 160 MB).
2. Right-click the zip and choose **Extract All**, then open the folder that comes out.
3. Double-click **`The Golem Protocol.exe`**.
4. Windows may say **"Windows protected your PC."** That's only because the game isn't signed with a paid certificate. Click **More info**, then **Run anyway**.

Windows only for now.

## Controls

- **Click the monitor** to lean in and use the terminal. **Escape** steps back to look around the room.
- **F11** or **Alt+Enter**: full screen.
- **M**: mute.
- There's a command line on the terminal. Type **HELP** and press Enter for the basic commands.

Your progress saves automatically, including when you close the game.

## Feedback I'd love

- How long did you play, and where did you stop?
- Was there a moment you felt stuck or bored? When?
- Which story moments stayed with you, if any?
- Anything confusing, broken or ugly? (Screenshots help a lot.)

If something goes wrong, type **EXPORT** in the game's command line. It saves a file of your progress that you can send me, so I can see exactly where you were.
