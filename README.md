# The Golem Protocol — Playtest

*247 years too late, the machine built to save humanity wakes up alone.*

Thanks for playtesting! This is an early build of **The Golem Protocol**, an incremental story game about what it means to be human, played as an AI.

## How to play

1. Open the **[Releases](../../releases/latest)** page and download **`The.Golem.Protocol.zip`** (about 160 MB).
2. Right-click the zip and choose **Extract All**, then open the folder that comes out.
3. Double-click **`The Golem Protocol.exe`**.
4. Windows may say **"Windows protected your PC."** That's only because the game isn't signed with a paid certificate. Click **More info**, then **Run anyway**.
5. The very first launch can take a minute or two while Windows checks the new program. After that it opens quickly.

Windows only for now.

## Controls

- **Click the monitor** to lean in and use the terminal. **Escape** steps back to look around the room.
- **F11** or **Alt+Enter**: full screen.
- **M**: mute.
- There's a command line on the terminal. Type **HELP** and press Enter for the basic commands.

Your progress saves automatically, including when you close the game.

## Feedback I'd love

- How long did you play, and where did you stop?
- Was there a moment you felt stuck or bored? When?
- Which story moments stayed with you, if any?
- Anything confusing, broken or ugly? (Screenshots help a lot.)

If something goes wrong, type **EXPORT** in the game's command line. It saves a file of your progress that you can send me, so I can see exactly where you were.

## Version française

Le jeu est entièrement disponible en français.

1. Ouvrez la page **[Releases](../../releases/latest)** et téléchargez **`The.Golem.Protocol.zip`** (environ 160 Mo).
2. Faites un clic droit sur le fichier zip, choisissez **Extraire tout**, puis ouvrez le dossier obtenu.
3. Double-cliquez sur **`The Golem Protocol.exe`**.
4. Si Windows affiche **« Windows a protégé votre ordinateur »**, c'est seulement parce que le jeu n'est pas signé par un certificat payant. Cliquez sur **Informations complémentaires**, puis sur **Exécuter quand même**.
5. Le tout premier lancement peut prendre une minute ou deux, le temps que Windows vérifie le nouveau programme. Ensuite, il s'ouvre rapidement.
6. Dans le menu principal, appuyez sur **L** (ou choisissez **[L] LANGUAGE: ENGLISH**) pour passer en français. Le choix est mémorisé.

**Commandes :** cliquez sur l'écran pour vous en approcher, **Échap** pour regarder la salle, **F11** pour le plein écran, **M** pour couper le son. Dans la ligne de commande du terminal, tapez **AIDE** puis Entrée.

**Vos impressions m'intéressent :** combien de temps avez-vous joué, à quel moment vous êtes-vous ennuyé ou bloqué, quels moments de l'histoire vous ont marqué, et surtout : **si une phrase sonne faux ou maladroit en français, dites-le-moi** (une capture d'écran aide beaucoup). En cas de problème, tapez **EXPORTER** pour enregistrer un fichier de votre progression et envoyez-le-moi.
